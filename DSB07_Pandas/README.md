### Exercise 01. Basic operations

Создан DataFrame `views` на основе файла `feed-views.log`. Значения `datetime` преобразованы в тип `datetime64[ns]`, после чего из них выделены отдельные признаки: год, месяц, день, час, минута и секунда.

Добавлен столбец `daytime`, разделяющий посещения по времени суток:

* `night` — 00:00–03:59;
* `early morning` — 04:00–06:59;
* `morning` — 07:00–10:59;
* `afternoon` — 11:00–16:59;
* `early evening` — 17:00–19:59;
* `evening` — 20:00–23:59.

Для классификации использован метод `cut`, а столбец `user` установлен в качестве индекса.

С помощью `count()` и `value_counts()` рассчитано количество записей и распределение посещений по времени суток. Данные отсортированы одновременно по часам, минутам и секундам.

Дополнительно определены минимальные и максимальные значения часа, наиболее часто встречающиеся значения часа и категории `daytime`. Найдены пользователи, посещавшие страницу в соответствующие периоды. С помощью `nsmallest()` и `nlargest()` получены три самых ранних и поздних посещения.

Метод `describe()` использован для получения основных статистических характеристик. На основе квартилей часа рассчитан межквартильный размах `iqr`, позволяющий определить наиболее характерный интервал посещений.

### Exercise 02. Preprocessing

Загружен исходный CSV-файл с данными об автомобилях, при этом столбец `ID` установлен в качестве индекса.

С помощью `count()` определено исходное количество наблюдений. Дубликаты удалены с учётом столбцов `CarNumber`, `Make_n_Model` и `Fines`, при совпадении записей сохранён последний вариант.

Проведён анализ пропущенных значений. Столбцы, содержащие более 500 пропусков, удалены с использованием параметра `thresh`. Пропуски в `Refund` заполнены предыдущими доступными значениями, а отсутствующие значения в `Fines` заменены средним значением соответствующего столбца.

Значения `Make_n_Model` разделены на отдельные столбцы `Make` и `Model` с использованием `apply()`. Исходный составной столбец удалён.

Подготовленный DataFrame сохранён в JSON-файл `auto.json` в следующем формате:

### Exercise 03. Selects and aggregations

JSON-файл `auto.json` загружен в DataFrame, а `CarNumber` установлен в качестве индекса.

Выполнены выборки автомобилей по различным условиям:

* штраф больше `2100`;
* штраф больше `2100` и `Refund` равен `2`;
* модель входит в список `Focus` и `Corolla`;
* номер автомобиля входит в заданный список.

Проведена группировка данных по марке и модели автомобиля. Рассчитаны медианные, минимальные и максимальные значения штрафов, их стандартное отклонение, а также количество штрафов для каждой группы. Это позволило оценить как размер штрафов, так и количество наблюдений, на которых основаны статистические показатели.

Отдельно выполнена агрегация по номерам автомобилей. Определены автомобили с наибольшим количеством нарушений и наибольшей суммой штрафов. Для лидирующих номеров выполнен дополнительный просмотр исходных записей.

Также сформирована таблица, позволяющая определить, встречаются ли одни и те же номера автомобилей с разными моделями.

### Exercise 04. Enrichment and transformations

Загружены данные из `auto.json`, а формат отображения числовых значений настроен таким образом, чтобы вещественные числа выводились с двумя знаками после запятой. Пропуски в столбце `Model` сохранены без изменений.

Исходный DataFrame обогащён 200 случайными наблюдениями, выбранными с `random_state = 21`. При этом сохранена согласованность комбинаций номера автомобиля, марки и модели. Полученный набор объединён с исходными данными в DataFrame `concat_rows`.

Добавлен столбец `Year` со случайными значениями от 1980 до 2019. Перед генерацией установлен `np.random.seed(21)`, после чего новый ряд объединён с DataFrame.

Создан отдельный DataFrame `owners`, содержащий номера автомобилей и фамилии их владельцев. Для генерации фамилий использован набор наиболее популярных фамилий США. Также добавлены дополнительные записи, удалены последние наблюдения и созданы новые номера автомобилей для проверки различных вариантов объединения данных.

Выполнены четыре типа объединения `fines` и `owners`:

* только общие номера автомобилей;
* все номера из обоих DataFrame;
* только номера из `fines`;
* только номера из `owners`.

На основе `fines` создана сводная таблица с суммами штрафов по годам. Подготовленные DataFrame `fines` и `owners` сохранены в CSV-файлы без индексов.

### Exercise 05. Pandas optimizations

Загружен файл `fines.csv` и реализовано вычисление показателя `fines / refund * year` для каждой строки несколькими способами.

Производительность вариантов сравнивалась с помощью `%%timeit`:

* цикл `for` с `iloc` и добавлением результатов в список;
* `iterrows()`;
* `apply()` с lambda-функцией;
* работа непосредственно с объектами `Series`;
* работа с массивами через `.values`.

Проведено сравнение производительности доступа к строкам DataFrame. Сначала строка с определённым `CarNumber` получалась без изменения индекса, после чего `CarNumber` устанавливался в качестве индекса и операция выполнялась повторно.

Исследовано потребление памяти с помощью `df.info(memory_usage='deep')`. Создана копия исходного DataFrame `optimized_df`, после чего выполнено уменьшение типов данных: `float64` преобразованы в `float32`, а целочисленные значения — в минимально подходящие числовые типы.

После оптимизации повторно проверены типы данных и объём используемой памяти. Столбцы типа `object` преобразованы в `category`, что позволило дополнительно сократить потребление памяти.

В завершение выполнена очистка памяти с использованием библиотеки `gc` и команды `%reset_selective`, при этом очищен только исходный DataFrame.
