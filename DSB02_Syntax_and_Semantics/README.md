### Exercise 02. Поиск по ключу

В скрипте реализована работа со словарями `COMPANIES` и `STOCKS`. Программа принимает название компании через аргумент командной строки и определяет соответствующий тикер и стоимость акций.

Для существующей компании выводится стоимость её акций, например:

```text

```

Для неизвестной компании выводится:

```text

```

При отсутствии аргументов или при передаче нескольких аргументов программа не выводит ничего.

### Exercise 04. Словари

Список кортежей преобразован в словарь, в котором числовые значения используются как ключи, а названия стран — как значения.

Поскольку одинаковые ключи могут соответствовать нескольким странам, структура данных позволяет сохранить несколько значений для одного числа. Результат выводится построчно в требуемом формате:

```text

'132' : 'Germany'
'178' : 'Spain'
```

Таким образом, выполнено преобразование исходного списка кортежей в структуру, удобную для поиска стран по соответствующим значениям.

Имена и фамилии приводятся к формату с заглавной первой буквой. Результат сохраняется в файл `employees.tsv`, при этом столбцы разделяются символом табуляции.

Второй скрипт принимает адрес электронной почты, находит соответствующего сотрудника в `employees.tsv` и формирует персонализированное приветственное сообщение, например:


Для формирования строк используются f-строки. Запрещённая конструкция `.format()` не применяется.

### Exercise 09. Шифр Цезаря

Реализован скрипт `caesar.py`, поддерживающий кодирование и декодирование текста с помощью шифра Цезаря.

Программа принимает три аргумента:

1. режим работы — `encode` или `decode`;
2. исходную строку;
3. величину сдвига.

При кодировании каждая буква сдвигается на указанное количество позиций в алфавите. При декодировании выполняется обратный сдвиг.

Пример работы программы:

```text
$ python3 caesar.py encode 'ssh -i private.key user@school21.ru' 12
eet -u bduhmfq.wqk geqd@eotaax21.dg
```

Обратное декодирование возвращает исходную строку:

```text
$ python3 caesar.py decode 'eet -u bduhmfq.wqk geqd@eotaax21.dg' 12
ssh -i private.key user@school21.ru
```

Также реализована проверка входных данных. При обнаружении кириллических символов вызывается исключение с сообщением:

```text
The script does not support your language yet.
```

При неправильном количестве аргументов также вызывается исключение.

### Exercise 09. Шифр Цезаря

Существует метод, называемый [шифром Цезаря](https://en.wikipedia.org/wiki/Caesar_cipher), который позволяет кодировать текст путём сдвига букв в алфавитном порядке. Например, зашифрованной версией `"hello"` может быть `"tqxxa"`, если использовать сдвиг на 12 позиций.

1. Напишите программу, которая будет кодировать или декодировать любую строку с использованием заданного сдвига в соответствии с переданными аргументами:

   ```
   $ python3 caesar.py encode 'ssh -i private.key user@school21.ru' 12
   eet -u bduhmfq.wqk geqd@eotaax21.dg
   $ python3 caesar.py decode 'eet -u bduhmfq.wqk geqd@eotaax21.dg' 12
   ssh -i private.key user@school21.ru
   ```

2. Если скрипту передана строка, содержащая кириллические символы, например, он должен вызвать исключение: `"The script does not support your language yet."` Если передано неправильное количество аргументов, также необходимо вызвать исключение.
