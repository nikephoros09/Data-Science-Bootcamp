# Pandas, SQL and Data Visualization

### Exercise 00. Line chart

Создано подключение к базе данных SQLite и получены даты посещений Newsfeed только для пользователей, без административных записей.

С помощью Pandas рассчитано количество посещений по каждому дню и сформирован DataFrame с агрегированными значениями. Построен линейный график количества просмотров по дням с заданными в упражнении параметрами размера, шрифта, заголовка и отображения подписей оси X.

После завершения работы соединение с базой данных закрыто.

### Exercise 01. Line chart with styles

Для анализа активности пользователей объединены данные о посещениях Newsfeed и коммитах. В расчёты включены только пользователи и только даты, для которых присутствуют оба типа активности.

На основе полученных данных построен линейный график с двумя показателями. График оформлен в соответствии с требованиями задания: задан размер фигуры и шрифта, настроено отображение временной шкалы и стилистические параметры.

Дополнительно определено количество дней, в которые число просмотров Newsfeed превышало 150.

### Exercise 02. Bar

Проведён анализ времени выполнения лабораторных работ пользователями. Данные о коммитах разделены на четыре периода суток:

* `night` — 00:00–03:59;
* `morning` — 04:00–09:59;
* `afternoon` — 10:00–16:59;
* `evening` — 17:00–23:59.

Рассчитано количество коммитов по времени суток и датам. На основе результатов построен столбчатый график по требованиям задания с выбранной цветовой палитрой и заданными параметрами оформления.

Определены два наиболее распространённых периода для выполнения лабораторных работ, а также дата с максимальным количеством коммитов, для которой дополнительно проверено соотношение вечерней и дневной активности.

### Exercise 03. Bar charts

Для каждого часа рассчитано среднее количество коммитов отдельно для рабочих и выходных дней. Часы без коммитов исключены из расчёта средних значений.

На основе полученных данных построен столбчатый график с двумя группами показателей. Размеры фигуры и шрифта настроены в соответствии с требованиями задания, а для визуализации выбрана отдельная цветовая палитра.

Определены часы с максимальным средним количеством коммитов в рабочие и выходные дни и проведено сравнение динамики активности между этими периодами.

### Exercise 04. Histogram

Сформированы два набора абсолютных значений количества коммитов: для рабочих дней и для выходных.

Построена гистограмма для сравнения распределения коммитов по часам. График выполнен с требуемым размером фигуры и уровнем прозрачности `0.7` для переднего распределения; остальные параметры оформления выбраны в соответствии с требованиями задания.

Определены четыре наиболее показательных часа, в которых суммарное количество коммитов в выходные дни превышало соответствующее значение для рабочих дней.

### Exercise 05. Boxplot

Загружены данные для анализа поведения тестовой и контрольной групп до и после первого посещения Newsfeed. Данные подготовлены и преобразованы в формат, необходимый для визуального сравнения распределений.

Построен boxplot, позволяющий сравнить медианы, разброс и выбросы между группами. График оформлен по требованиям задания: задан размер фигуры, необходимая цветовая палитра, размер заголовка, а также ширина линий рамок и медиан.

По графику определено приблизительное значение межквартильного размаха (`IQR`) контрольной группы до появления Newsfeed.

### Exercise 06. Scatter Matrix

Создан DataFrame с показателями пользователей тестовой группы:

* средняя разница между первым коммитом и дедлайном;
* количество посещений Newsfeed;
* количество коммитов.

При расчёте средней разницы и количества коммитов `project1` исключён. Количество коммитов получено из таблицы `checker`.

Построена матрица рассеяния с диагональными распределениями для анализа возможных линейных и нелинейных взаимосвязей между показателями. Визуализация выполнена с заданными в упражнении размерами точек, толщиной линий и размером фигуры.

На основании графика проанализированы взаимосвязи между количеством просмотров, количеством коммитов и средней разницей до дедлайна, а также характер распределения пользователей по этим показателям.

### Exercise 07. Heatmap

Проведён анализ абсолютного количества коммитов пользователей по дням недели и часам. В выборку включены только пользовательские записи из таблицы `checker`.

Для построения тепловых карт использованы абсолютные значения количества коммитов. Пользователи отсортированы по общему количеству выполненных коммитов, после чего подготовлены данные для визуального анализа активности.

Созданы две тепловые карты, отображающие распределение коммитов по дням недели и времени суток. Для визуализации выбраны подходящие цветовые палитры.

По графикам определены пользователи с наибольшим количеством коммитов во вторник и четверг, день недели с минимальной активностью, а также пользователь и час с максимальным количеством коммитов.

### Exercise 08. Seaborn

Проведён анализ активности пользователей в проекте `project1` на основе таблицы `checker`. В расчёт включены только пользовательские записи со статусом `ready`.

С помощью библиотеки Seaborn построен график динамики количества коммитов пользователей во времени. Визуализация оформлена по требованиям задания: использована выбранная цветовая палитра, задана ширина линий, серый фон, размеры графика и требуемые размеры шрифтов заголовка и подписей осей.

По графику определены пользователь, который практически постоянно лидировал по количеству коммитов, и пользователь, занимавший первое место только в течение короткого периода.
