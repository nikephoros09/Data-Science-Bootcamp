# Movielens Analytics

### 1. `Tags`

Работает с файлом тегов (`tags.csv`).

* **Загрузка:** Считывает CSV-файл вида `userId,movieId,tag,timestamp` и извлекает список тегов.
* **Анализ:**
* `most_words(n)` — топ-$n$ тегов с наибольшим количеством слов.
* `longest(n)` — топ-$n$ самых длинных тегов по количеству символов.
* `most_words_and_longest(n)` — пересечение самых длинных тегов и тегов с наибольшим количеством слов.
* `most_popular(n)` — топ-$n$ самых частых (популярных) тегов.
* `tags_with(word)` — поиск всех уникальных тегов, содержащих заданное слово.



---

### 2. `Movies`

Работает с файлом списка фильмов (`movies.csv`).

* **Загрузка:** Разбирает CSV-файл (используя функции обработки кавычек) вида `movieId,title,genres`.
* **Анализ:**
* `dist_by_genres()` — распределение (количество) фильмов по жанрам.
* `most_genres(n)` — топ-$n$ фильмов с наибольшим количеством жанров.
* `dist_by_release()` — распределение количества фильмов по годам выпуска (извлекает год из названия).



---

### 3. `Links`

Связывает локальные ID фильмов со строками в IMDb (`links.csv`) и собирает данные с веб-страниц IMDb.

* **Загрузка и парсинг:** Выгружает данные с сайта IMDb via `requests` и `BeautifulSoup` (название, режиссер, хронометраж, бюджет, мировые сборы).
* **Анализ:**
* `top_directors(n)` — топ-$n$ режиссеров по количеству представленных фильмов.
* `longest(n)` — топ-$n$ самых продолжительных фильмов.
* `most_expensive(n)` — топ-$n$ фильмов с наибольшим бюджетом.
* `most_profitable(n)` — топ-$n$ самых прибыльных фильмов (сборы минус бюджет).
* `top_cost_per_minute(n)` — топ-$n$ фильмов с самой высокой стоимостью одной минуты хронометража.



---

### 4. `Ratings`

Анализирует оценки фильмов (`ratings.csv`). Содержит два вложенных класса:

#### `Ratings.Movies`

* **Анализ оценок фильмов:**
* `dist_by_year()` — распределение выставленных оценок по годам их поставивших пользователей.
* `dist_by_rating()` — распределение количества оценок по их значениям (например, сколько двоек, пятерок).
* `top_by_num_of_ratings(n)` — топ-$n$ самых оцениваемых фильмов.
* `top_by_ratings(n, metric)` — топ-$n$ фильмов по средней (`average`) или медианной (`median`) оценке.
* `top_controversial(n)` — топ-$n$ самых противоречивых фильмов (с наибольшей дисперсией оценок).



#### `Ratings.Users` (наследует `Ratings.Movies`)

* **Анализ активности пользователей:**
* `u_distr_by_rating()` — распределение пользователей по количеству оставленных ими оценок.
* `u_avg_mdn_distr(metric)` — распределение средних/медианных оценок среди пользователей.
* `u_variance(n)` — топ-$n$ пользователей с наибольшей дисперсией (разбросом) в ставимых оценках.

### 5. `Tests`

Набор модульных тестов на `pytest`.

* Проверяет корректность работы методов классов (`Movies`, `Links`, `Ratings`, `Tags`), типов возвращаемых данных, структуры возвращаемых словарей и правильности сортировки результатов.
