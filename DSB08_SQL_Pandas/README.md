### Exercise 00. Select

Создано подключение к базе данных SQLite с использованием `sqlite3`. С помощью `pd.io.sql.read_sql()` получена схема таблицы `pageviews` и просмотрены первые десять записей.

Сформирован DataFrame `pageviews`, содержащий только необходимые данные пользователей. В выборку включены столбцы `uid` и `datetime`, исключены административные записи, а данные отсортированы по `uid` в возрастающем порядке.

Столбец `datetime` установлен в качестве индекса и преобразован в `DatetimeIndex`. После завершения работы соединение с базой данных закрыто.

### Exercise 02. Join

Создана аналитическая таблица `datamart` путём объединения таблиц `pageviews` и `checker` одним SQL-запросом.

В итоговую таблицу включены:

* `uid` — идентификатор пользователя;
* `labname` — название лабораторной работы;
* `first_commit_ts` — время первого коммита пользователя по лабораторной работе;
* `first_view_ts` — время первого посещения Newsfeed.

При формировании выборки сохранены ограничения по статусу `ready`, первой попытке и списку лабораторных работ. В таблицу включены только пользовательские записи, без администраторов. Временные значения преобразованы в тип `datetime64[ns]`.

На основе `datamart` сформированы две группы:

* `test` — пользователи, у которых зафиксировано первое посещение Newsfeed;
* `control` — пользователи без зафиксированного посещения.

Пропущенные значения `first_view_ts` в контрольной группе заменены средним временем первого посещения среди пользователей тестовой группы. Обе таблицы сохранены в базе данных для дальнейшего анализа.

### Exercise 03. Aggregations

Получена структура таблицы `test` и просмотрены первые десять записей.

С помощью SQL-запросов, объединяющих `test` с таблицей `deadlines`, рассчитано время между первым коммитом и дедлайном лабораторной работы. Значение разницы представлено в часах, а `project1` исключён из анализа как выброс из-за значительно более длительного срока выполнения.

Определены:

* минимальная разница между первым коммитом и дедлайном — в DataFrame `df_min` вместе с соответствующим `uid`;
* максимальная разница — в DataFrame `df_max`;
* средняя разница — в DataFrame `df_avg` без столбца `uid`.

Для проверки зависимости между активностью в Newsfeed и временем до дедлайна создан DataFrame `views_diff` со столбцами `uid`, `avg_diff` и `pageviews`. Для каждого пользователя рассчитаны средняя разница между первым коммитом и дедлайном и количество посещений Newsfeed.

С помощью метода `corr()` вычислен коэффициент корреляции между количеством просмотров страницы и средней разницей. После завершения анализа соединение с базой данных закрыто.

### Exercise 04. A/B testing

Подготовлено сравнение тестовой и контрольной групп для проверки влияния Newsfeed на поведение пользователей.

Для каждой группы с помощью SQL-запроса рассчитана средняя разница между первым коммитом и дедлайном до и после контрольного момента. Для тестовой группы контрольным моментом является первое посещение Newsfeed, а для контрольной группы используется среднее время первого посещения, рассчитанное по тестовой группе.

Созданы два DataFrame:

* `test_results` — результаты для пользователей, посетивших Newsfeed;
* `control_results` — результаты для пользователей, не посетивших Newsfeed.

Каждый DataFrame содержит показатели `before` и `after` в столбцах `time` и `avg_diff`. В расчёты включены только пользователи, для которых имеются наблюдения как до, так и после соответствующего момента.

Лабораторная работа `project1` исключена из анализа. Полученные результаты использованы для проверки гипотезы о том, что просмотр Newsfeed влияет на более раннее начало работы студентов над лабораторными заданиями.
