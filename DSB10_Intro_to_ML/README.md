# Intro to Machine Learning

### Exercise 00. Binary classifier

Подготовлен первый классификатор машинного обучения для определения того, был ли коммит выполнен в рабочий день или в выходной.

В качестве наблюдения использован отдельный день, а из временных меток выполнена генерация признаков. Для классификации выбраны два признака:

* количество коммитов до полудня;
* количество коммитов после полудня.

Сформированы матрица признаков `X` и целевая переменная `y`, после чего обучена модель бинарной классификации. Проведена оценка полученных результатов и проверена способность модели определять тип дня по активности пользователя.

### Exercise 01. Decision boundaries

Исследованы различные алгоритмы классификации и их границы принятия решений.

Обучена логистическая регрессия, а также рассмотрены SVM и дерево решений. Для каждого алгоритма проведена визуализация границ классификации и проанализировано, каким образом модели разделяют наблюдения на классы.

Проведено сравнение подходов и качества полученных классификаторов.

### Exercise 02. Multiclass

Реализована задача многоклассовой классификации, в которой целевая переменная содержит несколько возможных классов.

Для построения моделей обработаны как числовые, так и категориальные признаки. Категориальные значения преобразованы в формат, пригодный для использования алгоритмами машинного обучения.

Обучены и сравнены несколько классификаторов, включая Random Forest. Оценена важность признаков для разных моделей.

На основе данных о пользователе, времени, лабораторной работе и количестве попыток реализовано предсказание дня недели, в который был выполнен коммит.

### Exercise 03. Overfitting

Исследована проблема переобучения моделей, возникающая при оценке качества на тех же данных, которые использовались для обучения.

Для получения более объективной оценки выполнено разделение исходного набора данных на обучающую и тестовую выборки. Модели обучены на тренировочных данных, после чего их качество проверено на ранее не использовавшихся наблюдениях.

Дополнительно применена кросс-валидация с несколькими вариантами разбиения данных. Полученные результаты использованы для сравнения устойчивости моделей и выявления признаков переобучения.

### Exercise 04. Regression

Решена задача регрессии для прогнозирования средней разницы между дедлайном лабораторной работы и первым коммитом пользователя.

В качестве признаков использованы данные об активности пользователей, включая количество посещений Newsfeed и количество выполненных коммитов за период обучения.

Подготовлены признаки и целевая переменная, после чего обучена регрессионная модель. Проведена оценка способности модели прогнозировать среднее значение временной разницы для каждого пользователя.

### Exercise 05. Clustering

Проведено первое исследование методов обучения без учителя с использованием алгоритмов кластеризации.

Пользователи разделены на однородные группы на основе особенностей их поведения и активности. Полученные кластеры проанализированы с точки зрения различий между группами.

Результаты кластеризации позволяют выделить группы пользователей с похожими характеристиками поведения и использовать эти различия для дальнейшего анализа и разработки различных механизмов взаимодействия с каждой группой.
