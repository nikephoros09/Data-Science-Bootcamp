# UNIX Command Line Tools

## Краткое описание 

Проект посвящён освоению UNIX-инструментов командной строки для базовой работы с данными: сбору данных через API, их преобразованию, очистке, сортировке, подсчёту статистик и разбиению на части.

Основные инструменты: `curl`, `jq`, `cat`, `sort`, `uniq`, `sed`.

## Задания

### Exercise 00 — Первый shell-скрипт

Получить через HeadHunter API первые 20 вакансий по запросу `data scientist` с помощью `curl` и сохранить результат в `hh.json`. Для обработки JSON использовать `jq`.

### Exercise 01 — Преобразование JSON в CSV

Преобразовать `hh.json` в CSV с помощью `jq`. Выбрать поля:

* `id`
* `created_at`
* `name`
* `has_test`
* `alternate_url`

Добавить заголовки и сохранить результат в `hh.csv`.

### Exercise 02 — Сортировка файла

Отсортировать `hh.csv` сначала по `created_at`, затем по `id` в возрастающем порядке. Сохранить заголовок в первой строке.

### Exercise 03 — Очистка данных

Обработать названия вакансий и заменить их на уровень позиции:

* `Junior`
* `Middle`
* `Senior`
* `Middle/Senior` и другие комбинации найденных уровней
* `-`, если уровень не указан

Сохранить очищенные данные в отсортированном CSV-файле.

### Exercise 04 — Описательная статистика

Посчитать количество уникальных значений в столбце `name`, отсортировать результаты по количеству в порядке убывания и сохранить их в CSV с колонками `name` и `count`.

### Exercise 05 — Разбиение и объединение

Разделить результат Exercise 03 на отдельные CSV-файлы по дате `created_at`. Затем объединить полученные файлы обратно в один CSV.
