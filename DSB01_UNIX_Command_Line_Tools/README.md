# UNIX Command Line Tools

## Краткое описание

Проект посвящён освоению UNIX-инструментов командной строки для работы с данными: получению данных через API, их преобразованию, очистке, сортировке, подсчёту статистик и разбиению на части.

В результате работы выполнены получение, обработка и анализ данных о вакансиях с использованием `curl`, `jq`, `cat`, `sort`, `uniq` и `sed`.

### Exercise 00 — Получение данных через API

Получение через HeadHunter API первых 20 вакансий по запросу `data scientist` с помощью `curl` и сохранение полученного JSON-ответа в `hh.json`. Обработка структуры JSON с использованием `jq`.

### Exercise 01 — Преобразование JSON в CSV

Преобразование данных из `hh.json` в CSV-файл `hh.csv` с помощью `jq`. Формирование набора полей:

* `id`
* `created_at`
* `name`
* `has_test`
* `alternate_url`

Добавление заголовков соответствующих столбцов.

### Exercise 02 — Сортировка данных

Сортировка `hh.csv` по `created_at`, затем по `id` в возрастающем порядке. Сохранение заголовка в первой строке файла.

### Exercise 03 — Очистка данных

Очистка названий вакансий и приведение их к уровням позиции:

* `Junior`
* `Middle`
* `Senior`
* `Middle/Senior` и другие комбинации найденных уровней
* `-`, если уровень позиции не указан

Формирование очищенного и отсортированного CSV-файла.

### Exercise 04 — Описательная статистика

Подсчёт количества уникальных значений в столбце `name`, сортировка результатов по количеству в порядке убывания и сохранение статистики в CSV-файле с колонками `name` и `count`.

### Exercise 05 — Разбиение и объединение

Разбиение результата Exercise 03 на отдельные CSV-файлы по дате `created_at` и последующее объединение полученных файлов обратно в единый CSV-файл.
